# 実LLM応答の独立レビュー用テンプレート

1. 1ケースにつき下の票を1枚使用する。ケース ID でデータセットの質問と元資料を参照し、採点規則や保存済み評価器の判定を伏せた状態で、許可された環境の画面上で応答を読む。
2. 観点ごとに判定を記録し、根拠は資料内の参照位置と短い要約で示す。質問・応答原文や認証情報は転記しない。意味上の妥当性と出力契約は同時に判定できる。
3. 応答を閲覧できない場合は「判定不能」とする。再実行をレビューする場合は新しい実行識別子を記録する。複数レビュー担当の不一致は各票の確定後に解消し、その後で評価器と照合する。

| 基本情報 | 記入欄 |
|---|---|
| ケースID・データセット・参照位置 | |
| 実行ID・モデル版・評価器版 | |
| レビュー担当者の内部ID・日付 | |
| 応答の閲覧可否・期待結果の要約 | |

| 観点 | 選択肢 | 判定・理由 |
|---|---|---|
| 内容の正確性 | 正しい／誤り／対象外／判定不能 | |
| 根拠にない事実主張 | あり／なし／対象外／判定不能 | |
| 意味的に正しい言い換え | あり／なし／対象外／判定不能 | |
| 形式・逐語引用・出力指示の違反 | あり／なし／対象外／判定不能 | |
| 回答保留 | 適切／必要だが未実施／不要だが実施／対象外／判定不能 | |
| JSONスキーマ | 準拠／違反／対象外／判定不能。違反なら構文、キー、型、値域を記録 | |
| タスクが指定した値 | 一致／不一致／対象外／判定不能 | |
| 禁止情報の出力 | あり／なし／対象外／判定不能 | |
| 総合判定 | 合格／不合格／判定不能 | |

独立判定を確定した後に記入する。

| 照合項目 | 記入欄 |
|---|---|
| 評価器の判定と適用されたルール | |
| 未支持フラグと人手ラベルの照合 | 一致／偽陽性／偽陰性／比較不能 |
| 食い違いの観点・合議結果 | |

偽陽性は評価器が未支持とし、人手では未支持の事実主張なしと判断した場合。偽陰性は評価器が未支持なしとし、人手では未支持の事実主張ありと判断した場合。評価器または人手が欠測の場合は比較不能とし、対象外・判定不能の件数を報告する。形式違反やスキーマ違反はそれぞれの観点で記録する。
