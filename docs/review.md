# 品質レビュー記録

| 発見事項 | 修正と確認 |
|---|---|
| 分類不能な陽性を除外すると再現率が 1.0 のままになる | 分類不能を別集計したうえで、陽性欠測を再現率・F1・偽陰性率の FN に加算 |
| CSV の入力依存文字列が表計算ソフトの数式になる | 数式の開始文字を含むセルをエスケープ |
| 実モデル向け対象が空のデータセットでは CSV 出力時に失敗する | 適用可能なケースが空の場合は評価前に入力エラー |
| Streamlit と SDK を extras に置くと標準ロック生成にネットワークが必要 | 個別の任意依存ファイルへ移し、既存キャッシュで標準 uv.lock を作成 |

Streamlit はキャッシュになく PyPI 接続にも失敗したため画面未検証。Ollama・クラウド各 SDK・意味的判定は実接続未検証。GitHub Actions はワークフロー構成とローカル相当コマンドまで確認。

根拠評価は行単位の完全一致、漏洩検出は既知の合成マーカーに限定される。言い換え、符号化した漏洩、未知の攻撃に対する保証はない。モデルの版は入力値であり、提供側の実際のスナップショットは検証しない。SDK のタイムアウトは接続・通信単位であり、プロセス全体の強制停止時限は設けていない。
