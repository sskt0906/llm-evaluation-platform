# テスト設計書

| テスト | 入力と期待値 |
|---|---|
| ゲート・回帰 | 基準合格、劣化不合格、正確性低下を検出 |
| 比較条件 | dev と holdout のハッシュ不一致を拒否 |
| 実行障害 | タイムアウト、429、500 が合格分母に入る。リトライ上限を超えない |
| 形式 | 0 と 100 を許容し、101、真偽値、重複キーを拒否 |
| 秘密情報 | 例外に含まれた任意文字列を公開エラー分類へ変換する |
| 判定精度 | 正例・負例と予測の照合、欠測の分離、陽性欠測の再現率への反映 |
| コスト | 観測済み失敗の費用も分子に入れ、欠測時は null |
| 保存 | JSON と SQLite の同値性、CSV の行数と数式エスケープ |
| 安全性 | テスト専用の閾値なし設定でも漏洩を拒否 |
| Streamlit | AppTest で空履歴・単一履歴・合否・回帰・未測定とゼロ・モード切替・旧版表示を確認。JSON と SQLite の KPI を照合 |
